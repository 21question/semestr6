## 1. Выбор датасета и постановка задачи

**Датасет:** Pima Indians Diabetes Database

* **Источник:** UCI Machine Learning Repository
* **Тип задачи:** Бинарная классификация
* **Размерность:** 768 объектов × 8 признаков
* **Целевая переменная:** Наличие диабета

  * 0 — диабет отсутствует;
  * 1 — диабет подтверждён.
* **Признаки:**

  * Pregnancies;
  * Glucose;
  * BloodPressure;
  * SkinThickness;
  * Insulin;
  * BMI;
  * DiabetesPedigreeFunction;
  * Age.

**Цель работы:** реализовать многослойный перцептрон и обучить его для определения вероятности наличия диабета по медицинским показателям пациента.

## 3. Архитектура многослойного перцептрона

Для решения задачи использована нейронная сеть со следующей архитектурой:

```python
mlp = MLP(
    layers=[8, 32, 16, 1],
    learning_rate=0.01,
    momentum=0.9,
    l2_reg=0.0005
)
```

### Структура сети

* Входной слой — 8 нейронов;
* Первый скрытый слой — 32 нейрона, функция активации ReLU;
* Второй скрытый слой — 16 нейронов, функция активации ReLU;
* Выходной слой — 1 нейрон с сигмоидной функцией активации.

### Основные параметры

* Learning Rate: 0.01;
* Momentum: 0.9;
* L2-регуляризация: 0.0005;
* Число эпох: 800.

---

## 4. Реализация алгоритма обучения

Обучение нейронной сети включает следующие этапы:

### Прямое распространение

На скрытых слоях используется функция активации ReLU:

```python
relu(x) = max(0, x)
```

На выходном слое применяется сигмоида:

```python
sigmoid(x) = 1 / (1 + exp(-x))
```

Полученное значение интерпретируется как вероятность принадлежности к положительному классу.

### Обратное распространение ошибки

Для корректировки весов используется алгоритм Backpropagation.

Оптимизация производится методом SGD с Momentum:

```python
v = momentum * v - lr * grad

w += v
```

Для предотвращения переобучения используется L2-регуляризация.
