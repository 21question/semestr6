# Кейс 1. Доставка медикаментов в районные больницы (`civil_01`)

## 1. Исходные данные

### Объёмы запасов

| Поставщик | Количество |
| --------- | ---------: |
| Склад A   |         30 |
| Склад B   |         40 |
| Склад C   |         35 |
| **Всего** |    **105** |

### Потребности больниц

| Получатель | Потребность |
| ---------- | ----------: |
| Больница 1 |          20 |
| Больница 2 |          25 |
| Больница 3 |          30 |
| Больница 4 |          30 |
| **Всего**  |     **105** |

**Проверка:** суммарный запас равен суммарной потребности (105 = 105), поэтому задача является закрытой и не требует балансировки.

---

## 2. Математическая модель

Целевая функция:

[
\min Z=\sum_{i=1}^{3}\sum_{j=1}^{4} c_{ij}x_{ij}
]

Ограничения:

* для каждого склада:

[
\sum_{j=1}^{4}x_{ij}=S_i
]

* для каждой больницы:

[
\sum_{i=1}^{3}x_{ij}=D_j
]

* условия неотрицательности:

[
x_{ij}\ge0
]

---

## 3. Программная реализация

Для поиска оптимального решения использовалась функция `linprog()` из библиотеки `scipy.optimize` с методом `highs`.

```python
from scipy.optimize import linprog
import numpy as np

costs = np.array([
    [5, 7, 6, 10],
    [8, 4, 5, 7],
    [6, 6, 4, 5]
])

supplies = np.array([30,40,35])
demands = np.array([20,25,30,30])

res = linprog(...)
```

---

## 4. Полученные результаты

### Оптимальный план перевозок

|             | Больница 1 | Больница 2 | Больница 3 | Больница 4 |
| ----------- | ---------: | ---------: | ---------: | ---------: |
| **Склад A** |         20 |          0 |         10 |          0 |
| **Склад B** |          0 |         25 |          0 |         15 |
| **Склад C** |          0 |          0 |         20 |         15 |

**Минимальные транспортные затраты:** **520**.

**Вывод:** Оптимизация показала, что перевозки осуществляются преимущественно по направлениям с наименьшей стоимостью доставки. Некоторые маршруты не используются, так как они менее выгодны.

# Кейс 2. Организация школьного питания (`civil_02`)

## 1. Исходные данные

### Производственные мощности

| Комбинат   |   Запас |
| ---------- | ------: |
| Комбинат A |      40 |
| Комбинат B |      35 |
| Комбинат C |      30 |
| **Всего**  | **105** |

### Потребности школ

| Школа     |  Спрос |
| --------- | -----: |
| Школа 1   |     20 |
| Школа 2   |     25 |
| Школа 3   |     30 |
| Школа 4   |     15 |
| **Всего** | **90** |

Так как общий объём запасов превышает потребность:

[
105 > 90
]

задача является открытой. Для балансировки введён фиктивный потребитель с объёмом спроса 15 единиц.

---

## 2. Математическая постановка

Целевая функция имеет вид:

[
\min Z=\sum_{i=1}^{3}\sum_{j=1}^{5} c_{ij}x_{ij}
]

где пятый столбец соответствует фиктивному потребителю.

---

## 3. Реализация

```python
diff = supplies.sum() - demands.sum()

costs_ext = np.column_stack(
    [costs, np.zeros(costs.shape[0])]
)

demands_ext = np.append(
    demands,
    diff
)
```

После балансировки задача решается стандартным способом при помощи `linprog`.

---

## 4. Результаты

|                | Школа 1 | Школа 2 | Школа 3 | Школа 4 | Фиктивный |
| -------------- | ------: | ------: | ------: | ------: | --------: |
| **Комбинат A** |      20 |       0 |       0 |       5 |        15 |
| **Комбинат B** |       0 |      25 |       0 |      10 |         0 |
| **Комбинат C** |       0 |       0 |      30 |       0 |         0 |

**Вывод:** Избыточный объём продукции направляется фиктивному потребителю. Это позволяет преобразовать открытую задачу в закрытую без изменения экономического смысла модели.

# Кейс 4. Поставка запчастей на ремонтные базы (`military_02`)

## 1. Исходные данные

### Запасы

| Склад     |  Запас |
| --------- | -----: |
| Склад A   |     25 |
| Склад B   |     30 |
| Склад C   |     20 |
| **Всего** | **75** |

### Потребности

| Ремонтная база |  Спрос |
| -------------- | -----: |
| Рембаза 1      |     15 |
| Рембаза 2      |     20 |
| Рембаза 3      |     18 |
| Рембаза 4      |     30 |
| **Всего**      | **83** |

Так как

[
75 < 83
]

имеется дефицит ресурсов. Для балансировки вводится фиктивный поставщик с запасом:

[
83 - 75 = 8
]

---

## 2. Математическая модель

Целевая функция:

[
\min Z=\sum_{i=1}^{4}\sum_{j=1}^{4} c_{ij}x_{ij}
]

где четвёртый поставщик является фиктивным.

---

## 3. Реализация

Матрица транспортных затрат расширяется дополнительной строкой с нулевыми затратами, а вектор запасов дополняется величиной дефицита.

---

## 4. Результаты

|                         | Рембаза 1 | Рембаза 2 | Рембаза 3 | Рембаза 4 |
| ----------------------- | --------: | --------: | --------: | --------: |
| **Склад A**             |         5 |        20 |         0 |         0 |
| **Склад B**             |        10 |         0 |         0 |        20 |
| **Склад C**             |         0 |         0 |        18 |         2 |
| **Фиктивный поставщик** |         0 |         0 |         0 |         8 |

**Вывод:** Недостающий объём поставок отражён через фиктивного поставщика. Это позволяет корректно описать дефицит ресурсов и получить оптимальное решение задачи минимизации транспортных затрат.
